# V17 — approved owner signature

The owner approved the illustrated YHA signature concept. The site implements it with a blue/violet SVG monogram, pink orbital accents, a signature-style English name and readable English copyright text. The shared ownership component is rendered at build time and on protected server pages. CSS adjusts the horizontal desktop signature into a compact centered signature on phones.

The name and copyright remain accessible text. The SVG is decorative. A 13 KB locally hosted WOFF subset supplies the signature lettering; no third-party request is made by the browser. This font derives from Allura (The Allura Project Authors), distributed under SIL OFL 1.1, with license at `/assets/owner-signature-OFL.txt`. Upstream font Git blob: `dd197a26fb5d836bedb73aead3c6fc6f4c9ca864`. The subset is renamed Zyvoqix Owner Signature.

The original game creators, licenses, 71 game runtimes, site navigation, saves, profiles, backup formats and authentication remain unchanged. One ownership signature appears per current shell page.
