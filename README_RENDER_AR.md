# ZYVOQIX REBORN V6.1 - Render Static Site

هذه الحزمة مجهزة للنشر على Render كـ Static Site وهي لا تحتاج GPU أو سيرفر Node.js أو قاعدة بيانات لتشغيل الألعاب الداخلية.

## محتويات النشر
- public/: ملفات الموقع، التصميم، الألعاب الـ24 HTML5، والمكتبة.
- render.yaml: ملف إعداد Render الرسمي (Blueprint).

## إعداد مباشر على Render
1. أنشئ مستودع GitHub جديدًا باسم zyvoqix-reborn وادفع إليه محتويات هذه الحزمة (المجلد public وملف render.yaml في الجذر).
2. اربط Render بحساب GitHub ثم اختر New > Static Site والمستودع الجديد.
3. اختَر الفرع main.
4. Build Command: test -f public/index.html
5. Publish Directory: public
6. أنشئ الموقع وانتظر حالة Live، ثم افتح الرابط الحقيقي الذي يولده Render (يكون على نطاق onrender.com).

بديل: اختر New > Blueprint ثم المستودع؛ Render يقرأ render.yaml تلقائيًا.

## حدود واضحة
- الألعاب الـ24 الداخلية تعمل داخل الموقع مباشرة عبر HTML5؛ هناك 45 رابط لعبة ويب خارجي و10 روابط مشروعات سطح مكتب تتطلب تنزيلًا.
- هذه الحزمة لواجهة ثابتة، **ولا تتضمن تسجيل حسابات اللاعبين أو قاعدة حفظ سحابية**. النتائج والمفضلة محفوظة في متصفح الزائر.
- API القديم الخاص بـ Vercel Blob مستبعد من حزمة النشر الثابتة كي لا يوهم بوجود حسابات سحابية.
- استضافة Render الثابتة مجانية ضمن حدود الباندويث ودقائق البناء المسموح بها بالحساب.
- للتأكد من سلامة النشر اختبر الدخول، فلاتر الألعاب، لعبة من كل فئة، التوافق مع الموبايل وHTTPS.
